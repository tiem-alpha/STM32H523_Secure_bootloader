## Task Priority & Scheduling

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        TASK SCHEDULING                                       │
└─────────────────────────────────────────────────────────────────────────────┘

Priority (Lower = Higher Priority):
────────────────────────────────────────
  0: Init Task      (One-shot, highest)
  1: Verify Task    (One-shot)
  2: Update Task    (Event-driven)
  3: Comm Task      (Event-driven)
  4: Crypto Task    (Synchronous)
  5: Storage Task   (Event-driven)
  6: Debug Task     (Async)
────────────────────────────────────────

Task Communication:
────────────────────────────────────────
  - Init → Verify: Direct call
  - Verify → Boot: Direct call
  - Update → Storage: Queue
  - Comm → Crypto: Queue
  - All → Debug: Ring buffer
────────────────────────────────────────
```
