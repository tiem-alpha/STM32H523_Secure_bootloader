## Data Flow Summary

| Stage | Input | Output | Description |
|-------|-------|--------|-------------|
| Build | Source Code | Signed Binary | Compile & Sign |
| Transfer | TCP Packet | UART Stream | Protocol Bridge |
| Verify | FW Binary | Valid/Invalid | Signature Check |
| Store | Valid FW | Flash Write | Bank Update |
| Boot | Metadata | App Jump | Bank Switch |
